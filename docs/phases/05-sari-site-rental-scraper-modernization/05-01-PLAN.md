# Plan 05-01: Live Gate G0, Test Suite & Daily Scheduling

<objective>
Prove the selenium engine live (gate G0), lock the behavior in with a pytest
suite, and schedule daily runs.
</objective>

<tasks>

### Task 05-01-01: Live smoke run — day-1 ritual (cold profile)

Run after the site's IP cooldown passes (do NOT test while the IP is flagged):

```bash
python InflationItems/Codes/HousesRent/KayseriSivasTokat/engine_selenium.py --city kayseri --rooms 3+1
```

Expected: Chrome opens with the persistent profile; if Turnstile appears, the
human solves it once (visible window + ENTER); bracket resolution proceeds; CSV
rows land in `InflationItems/Datas/HousesRent/Kayseri/<date>.csv` with header
`District,Rooms,Price,ilanId`.

**Pass criteria (G0):** at least one bracket resolves with listings on a cold
profile after the manual solve; no exception kills the run; profile dir
`SeleniumProfile/` is written.

### Task 05-01-02: Live warm-session run — all cities

```bash
python InflationItems/Codes/HousesRent/KayseriSivasTokat/main.py --rooms 3+1
```

Expected: three cities complete; **zero manual solves** (warm profile trust);
checkpoint cleared only after all cities finish; per-city row counts within
±15% of recon estimates (Kayseri ~2,020 / Sivas ~1,020 / Tokat ~960).

**Pass criteria:** all cities complete, row counts plausible, CSV schema exact.

### Task 05-01-03: Pytest suite with Turkish fixtures

Create `tests/` (or `InflationItems/Codes/HousesRent/KayseriSivasTokat/tests/`) covering:

- `parse_page`: Turkish fixture rows (`17.900 TL`, `10 Ağustos 2026`,
  `tr[data-id]` rows), 3+1 filter on/off, ilanId last-column schema.
- `normalize_price`: `17.900 TL`, `16000`, `1.000.000 TL`, `N/A`, garbage.
- `extract_total_listings`: `.result-text` "N ilan bulundu" + pager fallback.
- `page_needs_solve`: Cloudflare/Turnstile/login-wall HTML samples.
- `save_incremental`: header written once, append-only, extras dropped.
- `load/save/clear_checkpoint`: atomic write, corrupted-file fallback.
- `AdaptiveDelayTracker`: bounds after success streaks and failures.
- `_bracket_url`/`resolve_brackets` split logic with a fake driver.

Run with `uv run pytest` per modern-python conventions.

### Task 05-01-04: Daily-run scheduler wrapper

- GitHub Actions workflow (cron) on a self-hosted runner with the profile
  directory persisted as a cache/artifact, OR a documented Windows Task
  Scheduler entry.
- Invocation: `python main.py --resume` (crash-safe) with per-day date-stamped
  output; alert on `crawl_runs` failure (once Mongo exists) or missing CSVs.
- Document in `docs/DEVELOPMENT.md` (run commands) and `docs/APPROACH.md` §8.

### Task 05-01-05: Update docs and commit
